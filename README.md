# Indian_Economy_Analysis
# 🇮🇳 Indian Economy Analysis

##  Project Overview

**Indian Economy Analysis** is a data analysis project focused on exploring and understanding important economic trends and indicators of India using **Python, Pandas, NumPy, Matplotlib, and Seaborn**.

The project performs data cleaning, exploratory data analysis (EDA), statistical analysis, and visualization to identify meaningful patterns and trends in the Indian economy.

The complete analysis is available in the Jupyter Notebook:

 **[Indian_Economy_Analysis.ipynb](Indian_Economy_Analysis.ipynb)**

---

The main objectives of this project are:

##  Analysis Process

The project follows a structured data analysis workflow:

### 1. Data Collection

Economic data is loaded into the Python environment for further analysis.

### 2. Data Understanding

The dataset is examined to understand:

* Number of rows and columns
* Data types
* Statistical properties
* Missing values
* Duplicate records
* Distribution of variables

### 3. Data Cleaning

The dataset is prepared for analysis by:

* Checking missing values
* Checking duplicate records
* Handling inconsistent data
* Converting data types where required
* Preparing variables for visualization and analysis

### 4. Exploratory Data Analysis

EDA is performed to discover:

* Economic trends
* Year-wise changes
* Relationships between variables
* Growth patterns
* Distribution of economic indicators
* Significant variations in the data

### 5. Data Visualization

Different visualizations are used to make the analysis easier to understand, including:

* 📊 Bar Charts
* 📈 Line Charts
*  Scatter Plots
*  Correlation Heatmaps
*  Trend Visualizations
*  Distribution Plots

### 6. Insights

The final stage focuses on extracting useful observations and conclusions from the analyzed economic data.

## How to Run the Project

### Option 1: Run using Jupyter Notebook

Clone the repository:

```bash
git clone https://github.com/Mant-0957/Indian_Economy_Analysis.git
```

Navigate to the project folder:

```bash
cd Indian_Economy_Analysis
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Start Jupyter Notebook:

```bash
jupyter notebook
```

Then open:

```text
Indian_Economy_Analysis.ipynb
```

---

### Option 2: Run using Google Colab

You can also upload the notebook to **Google Colab** and execute the cells directly.
